# Backend

Modulo reservado para la API principal de Recetas Familiares.

Stack objetivo:

- Java 21 LTS
- Spring Boot
- Spring Security
- Spring Data JPA
- MySQL
- Flyway
- JWT y refresh tokens
- OpenAPI/Swagger

Responsabilidades iniciales:

- autenticacion;
- usuarios;
- familias;
- recetas;
- ingredientes;
- listas de compra;
- menus;
- sincronizacion;
- validacion de ownership familiar.

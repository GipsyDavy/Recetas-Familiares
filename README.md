# Recetas Familiares

Aplicacion multiplataforma para gestion familiar de recetas, ingredientes, menus, listas de compra y memoria culinaria compartida.

## Modulos

- `backend/`: API Spring Boot, seguridad, persistencia MySQL y sincronizacion.
- `android/`: aplicacion Android nativa con experiencia offline-first.
- `desktop/`: aplicacion JavaFX para uso principal en escritorio o cocina.
- `database/`: migraciones, semillas y documentacion de base de datos.
- `docs/`: arquitectura, UX, contratos API, seguridad y roadmap.

## Estado

Repositorio inicial preparado como monorepo. La implementacion real de cada modulo se ira creando por fases.

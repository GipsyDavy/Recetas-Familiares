# Roadmap

## Fase 0 - Base del repositorio

- Monorepo limpio.
- Git y GitHub configurados.
- `.gitignore` global.
- Documentacion inicial.

## Fase 1 - Backend base

- Proyecto Spring Boot.
- MySQL y Flyway.
- Autenticacion JWT.
- Usuarios y familias.
- OpenAPI.

## Fase 2 - Recetas MVP

- CRUD de recetas.
- Ingredientes y pasos.
- Favoritos.
- Busqueda simple.
- Paginacion.

## Fase 3 - Desktop MVP

- Proyecto JavaFX real.
- Login.
- Dashboard.
- Listado y detalle de recetas.
- Crear y editar recetas.

## Fase 4 - Android MVP

- Proyecto Android real.
- Login.
- Recetas.
- Cache Room inicial.
- Sincronizacion basica.

## Fase 5 - Sincronizacion

- Pull incremental.
- Push de cambios locales.
- Soft delete.
- Last Write Wins inicial.

## Fase 6 - Experiencia premium

- Modo cocina.
- Menus semanales.
- Lista de compra.
- Stock familiar.
- Fotos.
- Dark mode.
